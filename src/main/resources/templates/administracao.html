Administração

Gerenciamento da base de dados utilizada pelo sistema.

Importar base de OPs e lotes

Importe a planilha contendo as OPs atualmente disponíveis. Os dados serão utilizados para auxiliar o preenchimento das informações na tela de Produção.

Formato esperado da planilha:
OP LOTE PRODUTO ETAPA

A primeira linha da planilha deve conter os títulos das colunas. Os registros devem começar na segunda linha.

Como funciona a base importada

1. Importação

A planilha com as OPs em andamento é importada para o banco de dados do sistema.

2. Consulta

Ao informar uma OP na tela de Produção, o sistema procura automaticamente os dados existentes na base.

3. Atualização manual

Caso a OP não exista na base importada, o usuário poderá preencher normalmente as informações do lote.
